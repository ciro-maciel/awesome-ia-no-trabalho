## Etiquetas

Cada ítem indica qué es. Las etiquetas al lado ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrarlo. Los ítems con la etiqueta "del autor" son hechos por Ciro Cesar Maciel y siguen las mismas reglas que todos los demás.
