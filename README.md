## Por profissão

- [Awesome IA no escritório](https://go.mymarketing.click/iatrab-awesome-ia-no-escritorio) - IA para secretárias, assistentes e auxiliares administrativos: assistentes, privacidade, redação oficial e golpes que chegam por e-mail. `grátis`
- [Awesome IA no pequeno negócio](https://go.mymarketing.click/iatrab-awesome-ia-no-pequeno-negocio) - IA para o MEI e o pequeno empresário: assistentes, privacidade, as regras do MEI e do Simples, do consumidor e da LGPD para quem é pequeno. `grátis`
- [Awesome IA no primeiro trabalho](https://go.mymarketing.click/iatrab-awesome-ia-no-primeiro-trabalho) - IA para quem está começando a trabalhar: assistentes, privacidade, onde procurar vaga, os direitos do primeiro emprego e os golpes da vaga falsa. `grátis`

## Etiquetas

Cada item diz o que é. As etiquetas ao lado ajudam a escolher: oficial quando vem de quem define o padrão, código aberto quando o código está publicado, grátis ou pago pelo modelo de uso, API e SDK pelo jeito de integrar. Os itens com a etiqueta "do autor" são feitos por Ciro Cesar Maciel e seguem as mesmas regras de todos os outros.
