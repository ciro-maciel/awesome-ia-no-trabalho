Untuk yang ingin memakai AI di tempat kerja tanpa membocorkan data klien, murid, atau perusahaan, dan tanpa percaya begitu saja pada semua yang ditulisnya. Ini pintu masuknya: yang berlaku untuk semua orang ada di sini, dan tiap profesi punya daftarnya sendiri, dengan standar dan sumber resmi masing-masing.

## Label

Setiap item menjelaskan apa itu. Label di sebelahnya membantu memilih: resmi jika berasal dari pihak yang menetapkan standar, open source jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, serta API dan SDK menurut cara integrasinya. Item dengan label "buatan penulis" dibuat oleh Ciro Cesar Maciel dan mengikuti aturan yang sama dengan item lainnya.
